## 1. 로봇 규정 (자동차)
1. 지정된 로봇 구성품으로 만든 로봇으로 자율 주행
2. 경연 중 경연자 · 외부와 **유선 · 무선 통신 금지**
3. 로봇팔은 자동차를 **스스로 감지**해서 움직인다. 사람이 시작 신호를 주지 않는다

## 2. 주행 규정 · 점수
| # | 규정 | 점수 |
|---|---|---|
| 1 | 정해진 도로 폭 안에서만 주행 | -10 |
| 2 | 출발 신호는 심판이 정함. 신호 후 10초 동안 안 움직이면 감점 | -10 |
| 3 | 로봇에 달린 스위치로 출발 신호 전달 | -5 |
| 4 | 움직일 때 녹색 LED ON · 빨강 OFF, 멈췄을 때 녹색 OFF · 빨강 ON | -5 |
| 5 | LED 제어를 빵판 + Raspberry ROS ↔ Host 통신으로 구현 | **+15** |
| 6 | 빨간 네모 횡단보도 앞에서 반드시 멈췄다가 출발 | -10 |
| 7 | 도로 화살표 인식 → 그 방향 노란 LED 점멸 반복 → 그 방향으로 주행 | -10 |
| 8 | 교차로에서 표지판 인식 → 그 방향으로 | -10 |
| 9 | 신호등을 보면 먼저 멈추고 신호에 맞게 주행 | -10 |
| 10 | 정지 · 주차 구간에서 라인 안에 정확히 주차 | -10 |
| 11 | 주차 완료 표시로 모든 LED 점멸 | -5 |
| 12 | Start → Stop 시간 1 · 2 · 3등 | **+15 / +10 / +5** |

코스: ① Start → ② Go Straight (표지판 + 횡단보도) → ③ 로봇팔 앞 (상차) → ④ Turn Right → ⑤ 가운데 → ⑥ Parking · Stop. 빨간 네모 = 멈춰야 하는 횡단보도. 신호등 · Go Straight 표지 있음.

## 3. 로봇팔 규정 (팀마다 ROS2 DOMAIN ID 다르게)
| # | 규정 | 점수 |
|---|---|---|
| 1 | 전원 켜면 스스로 대기 자세 (그리퍼 카메라가 위에서 도로를 내려다봄) | -5 |
| 2 | 출발 전 심사위원이 자동차 바구니에 빨간/파란 포스트잇으로 주문 색 표시. 팀은 색을 입력하지 않음 | |
| 3 | 그리퍼 카메라로 포스트잇 색을 읽고 받침대에서 같은 색 공을 집어 바구니에. 다른 색 | **-20** |
| 4 | 넣은 뒤 ROS2 로 자동차에 상차 완료 알리고 대기 자세로 | |
| 5 | 집기 · 넣기 실패 시 3차 시도까지. 떨어진 공은 해당 팀원이 받침대 원래 자리에 | |
| 6 | 2차 · 3차 시도에서 성공 | -5 / -10 |
| 7 | 3차까지 실패하면 로봇팔이 실패를 알리고 자동차는 공 없이 주행 | **-30** |
| 8 | 공은 주차를 마칠 때까지 바구니 안 | -10 |
| 9 | 로봇팔 Pi ↔ 자동차 Pi ROS2 통신은 허용 (외부 통신 금지의 예외) | |

### 상차 구역
1. 모니터 나무 받침대 (가로 54 cm) 를 맵 위쪽에 둔다. 위치는 강사가 테이프로 고정
2. 빨간 공 = 받침대 **왼쪽**, 파란 공 = **오른쪽** (지름 3.0 cm 스펀지 공). 세부 위치는 팀이 정하고 테이프로 고정 가능 (왼빨 · 오파는 유지)
3. 자동차의 상차 정지 위치는 로봇팔이 닿는 범위 안에서 자유롭게 정한다

## 4. 로봇팔 구현 계획 (제안 — 사용자와 확인하며 진행)
감점이 큰 것: 색 틀림 -20, 3번 실패 -30 → **색 판정 신뢰도**와 **한 번에 집기**를 가장 단단하게.

| 단계 | 파일 (제안) | 내용 |
|---|---|---|
| 0 | `mission/m0_teach_poses.py` | 토크 끄고 손으로 자세 저장: `wait` (대기, 카메라가 도로 봄), `above_red`/`red`, `above_blue`/`blue`, `above_basket`/`basket`. 받침대 · 상차 정지 위치가 고정이라 **티칭 자세가 카메라 매핑보다 안정적** |
| 1 | `m1_wait_pose.py` | 전원 켜면 자동 실행 (systemd 또는 컨테이너 entrypoint) → `wait` 자세 |
| 2 | `m2_detect.py` | 그리퍼 카메라로 ① 자동차/바구니 도착 감지 (포스트잇 색 덩어리가 화면 정해진 영역에 N 프레임 연속) ② 색 판정: 여러 프레임 **투표** + 면적 · 비율 문턱, 애매하면 다시 봄 |
| 3 | `m3_pick_place.py` | 해당 색 쪽 `above → 내려가서 집기 → 들기` → **잡았는지 확인** (그리퍼를 닫았을 때 % 가 공 크기만큼 남는지; 다 닫히면 놓친 것) → `above_basket → basket → 놓기` → (선택) 카메라로 바구니 안 공 확인 |
| 4 | `m4_ros_link.py` | ROS2: 자동차 Pi 와 같은 DOMAIN ID. 예) `/mission/load_done` (std_msgs/String: `ok` / `fail`). 차가 도착 신호를 줄지(허용 범위 확인)는 강사에게 확인 |
| 5 | `mission_main.py` | 상태 기계: WAIT → DETECT → PICK (최대 3회) → PLACE → REPORT → WAIT. 실패 3회면 실패 동작(예: 그리퍼 흔들기) + `fail` 발행. 모든 경로 `try/finally` 로 대기 자세 → 토크 끄기 → 닫기 |

확인할 것 (강사 / 팀): 그리퍼 카메라 장착 · 장치 번호, 자동차 도착을 ROS2 로 알려도 "스스로 감지" 로 인정되는지, 바구니 크기, 상차 정지 위치.

## 5. 팁
- **동작이 끝나면 연결 종료**: 대기 자세로 옮기기 → `set_all_torque(False)` → `disconnect()`. `try/finally` 로 감싸면 Ctrl+C 에도 실행.
- **모터 응답 없음**: 포트 보이는지 → 권한 → 한 프로그램만 → 모터 LED → 선 다시 꽂기 → ping ID 1~6.
- **RGB LED**: `/ros_robot_controller/set_rgb` 에 `RGBStates` (LED index 1 · 2) 발행.
